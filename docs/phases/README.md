\# Smart Greenhouse Course Phases



The Smart Greenhouse application is developed incrementally throughout the Design Patterns 2026 course.



\## Required phases



1\. Phase 1 — Project skeleton

2\. Phase 2 — Factory Method

3\. Phase 3 — Abstract Factory

4\. Phase 4 — Builder

5\. Phase 5 — Adapter

6\. Phase 6 — Strategy

7\. Phase 7 — Facade

8\. Phase 8 — State

9\. Phase 9 — Decorator

10\. Phase 10 — Command

11\. Phase 11 — Observer

12\. Phase 12 — API, WebSocket and hardening



\## Optional enrichment



13\. Phase 13 — Dashboard polish

14\. Phase 14 — Tests, documentation and demo



The phases should be completed in order because later phases build on the architecture and database structure created in earlier phases.
